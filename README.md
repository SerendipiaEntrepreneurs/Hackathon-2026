## Cómo participar
0. Inicia sesión en GitHub (o crea tu cuenta gratis en github.com).
1. Haz clic en el botón verde **Use this template**. o ingresa el enlace https://github.com/SerendipiaEntrepreneurs/Hackathon-2026/generate
2. Elige **Create a new repository**.
3. Ponle a tu repositorio el nombre de tu equipo.
4. Trabaja ahí y sube tu proyecto.
5. Al terminar, envía el enlace de tu repositorio a los organizadores por whats app 2224266026
