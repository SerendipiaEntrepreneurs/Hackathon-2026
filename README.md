## Cómo participar
1. Haz clic en el botón verde **Use this template**.
2. Elige **Create a new repository**.
3. Ponle a tu repositorio el nombre de tu equipo.
4. Trabaja ahí y sube tu proyecto.
5. Al terminar, envía el enlace de tu repositorio a los organizadores.
